# Harsh Raj | Futuristic Portfolio 🚀

A modern, high-performance portfolio website built with React, TypeScript, and Vite, featuring stunning animations powered by GSAP.

🔗 **Live Website:** [https://gsap-portfolio-delta.vercel.app/](https://gsap-portfolio-delta.vercel.app/)

## ✨ Features

- **Immersive GSAP Animations:** Smooth scroll triggers, hover effects, and entrance animations for a premium user experience.
- **Modern Tech Stack:** Built with React 18, TypeScript, and Vite for optimal performance and developer experience.
- **Fully Responsive:** Tailored for seamless viewing across all devices (mobile, tablet, desktop) using Tailwind CSS.
- **Glassmorphism Design:** A futuristic, sleek UI with frosted glass effects and dynamic gradients.
- **Working Contact Form:** Integrated with Web3Forms for seamless message delivery.
- **Lucide Icons:** Beautiful, consistent iconography throughout the site.

## 🛠️ Built With

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/justHarshraj/GSAP-PORTFOLIO.git
   cd "GSAP PORTFOLIO "
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:5173` to see the application running.

## 📦 Building for Production

To create a production-ready build:

```bash
npm run build
```
This will generate optimized static assets in the `dist` directory, ready to be deployed to platforms like Vercel, Netlify, or GitHub Pages.
